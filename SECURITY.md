# Política de Segurança

## Versões suportadas

Este é um projeto pessoal de site estático. Não há uma matriz formal de versões com suporte; vulnerabilidades que afetem os arquivos do repositório ou o fluxo de desenvolvimento podem ser reportadas conforme descrito abaixo.

## Como reportar uma vulnerabilidade

Por favor, **não publique detalhes de uma vulnerabilidade em uma issue, pull request ou discussão pública** antes que ela possa ser avaliada.

Envie um e-mail para **lucasgabrieldomontegomes@gmail.com** com, se possível:

- uma descrição do problema e seu possível impacto;
- etapas para reproduzi-lo;
- arquivos ou funcionalidades afetados;
- uma sugestão de correção ou mitigação, se houver.

## O que esperar

A pessoa mantenedora buscará confirmar o recebimento, avaliar o relato e, se necessário, solicitar informações adicionais. O prazo e a solução dependem da gravidade e da complexidade do problema. A divulgação pública deve ocorrer somente depois de coordenada com a pessoa mantenedora e de uma correção ou mitigação adequada, quando possível.

## Escopo

Esta política cobre problemas de segurança nos arquivos-fonte, configuração do projeto e ferramentas de desenvolvimento mantidas neste repositório. Serviços externos vinculados pelo site podem ter políticas próprias.
